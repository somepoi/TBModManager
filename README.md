Менеджер модов для визуальной новеллы ["Зайчик"](https://store.steampowered.com/app/1421250/Tiny_Bunny/).

## Описание

TBModManager добавляет в игру менеджер модов. Менеджер сканирует папку игры, находит все файлы `mod.ini` и показывает их списком. Кликаешь на мод — он запускается.

Интерфейс сделан в стиле игры. Поиск работает по названиям, описаниям и авторам. Можно сортировать по алфавиту в обе стороны.

Поддерживает 6 языков: русский, английский, арабский, китайский, итальянский, японский, турецкий.

## Установка

### Для пользователей

1. Помести `launcher.exe` в постоянную удобную папку и запусти его
2. Выбери папку Tiny Bunny, в которой находятся `TinyBunny.py` и каталог `game`
3. Если локальный компонент не подключился автоматически, нажми «Установить игровые компоненты» и дождись успешной установки
4. Нажми "Запустить игру!" в лаунчере или просто запусти Tiny Bunny в Steam.

### Для разработчиков

#### Требования
- **Python**: 3.11.x
- **PDM**: 2.x

1. Открой рабочую копию с новой реализацией. После публикации изменений её можно получить клонированием репозитория:
```bash
git clone https://github.com/somepoi/TBModManager.git TBModManager
cd TBModManager
```

2. Установи зависимости:
```bash
pdm install
```

3. Запусти программу:
```bash
pdm run run-main
```

Лаунчер автоматически подключит исходники из `renpy/`. Последующие изменения `.rpy` и ресурсов доступны игре напрямую благодаря symlink.

#### Проверки

```bash
pdm run run-tests
```

Тесты проверяют создание настоящих ссылок, сохранение предыдущей установки, восстановление после ошибки, распаковку компонента, выбор игры и запуск без блокировки интерфейса. На Windows проверяется junction; на macOS/Linux тот же набор проверяет symlink.

#### Сборка исполняемого файла

```bash
pdm run run-build
```

Исполняемый файл появится в папке `dist/launcher.exe`

## Использование

1. Запусти лаунчер из любой папки и выбери установку Tiny Bunny
2. Выбери нужные опции:
   - **Режим разработчика** — для доступа к функциям RenPy для разработчиков
   - **Внутриигровая консоль** — для выполнения команд прямо в игре (Shift+O)
   - **Внешняя консоль** — для просмотра логов и ошибок в отдельном окне
3. Нажми "Запустить игру!"
4. Игра запустится с выбранными параметрами

### Настройки сохраняются автоматически

Лаунчер нужно запустить только один раз, чтобы выставить настройки. Дальше просто запускаешь игру, и менеджер модов будет доступен.

Все выбранные опции сохраняются в файл `game/TBModManager.ini` и автоматически восстанавливаются при следующем запуске.

## Как создать мод

Положи файл `mod.ini` в корневую папку своего мода, затем пропиши в нём поля из раздела [Формат mod.ini](#формат-modini)

Пример созданного мода (с .ini файлом, сценарием и аватаркой):

```
game/
└── YourMod/
    ├── mod.ini
    ├── script.rpy
    └── images/
        └── avatar.png
```

### Формат mod.ini

```ini
[your_mod_label]
name = Мой мод
description = Описание мода
avatar = YourMod/images/avatar.png
authors = Автор 1\nАвтор 2\nАвтор 3
```

**Поля:**

- `[section_name]` - Ren'Py label, который запускает мод (должен существовать в твоём .rpy файле)
- `name` - Название мода
- `description` - Текстовое описание мода, есть поддержка `\n` для переносов строк
- `avatar` - Путь к картинке
- `authors` - Имя автора(ов)

### Пример script.rpy

```renpy
label your_mod_label:
    scene bg black
    "Hello world!"

    return
```

Имя label в квадратных скобках `[your_mod_label]` в `mod.ini` должно совпадать с именем вступительного лейбла в твоём моде.
